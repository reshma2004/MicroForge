## Reporting a Vulnerability
If you discover a potential security vulnerability within this project, please **do not open a public issue**. Publicly disclosing vulnerabilities can put our users at risk.

Instead, please report it through our preferred private contact channel:
* **Email:** [Insert Security Email Address Here]

## Scope
This policy covers security concerns related to:
* Sensitive document data and encryption
* Secure storage mechanisms
* Authentication and authorization logic
* API endpoints and data transmission

## Responsible Disclosure & Timeline
To ensure a safe and coordinated response, we ask that you follow these guidelines:
1. **Acknowledgement:** We will acknowledge receipt of your report within 3 business days.
2. **Investigation:** We will provide an initial assessment of the issue and a projected timeline for a fix.
3. **Confidentiality:** We request that you keep the vulnerability confidential until we have had an opportunity to address it and release a patch.

## Our Commitment
MicroForge handles sensitive legal documents and prioritizes GDPR compliance and user privacy. By reporting vulnerabilities privately, you help us maintain a secure environment for all startups and entrepreneurs using the platform.
